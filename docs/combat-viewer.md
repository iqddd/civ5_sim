# Пошаговый просмотр матчей

Локальный веб-просмотрщик читает сохранённые реплеи. Перед показом он
исполняет команды через боевое ядро и сверяет результаты и SHA-256 каждого
состояния. Нужна собранная библиотека боя; AI-библиотека для просмотра не нужна.

Из корня проекта:

```powershell
.venv\Scripts\python.exe tools\view_combat.py build\combat-ai-v1-final --port 8766
```

Открыть [просмотрщик](http://127.0.0.1:8766). Аргументом может быть каталог
одного матча, каталог с множеством матчей или отдельный `replay.json`.
Сервер принимает подключения только с этого компьютера.

- Кнопки ‹ / › и клавиши ← / → переходят на одну команду.
- Ползунок позволяет сразу выбрать любую позицию. Шаг 0 — расстановка;
  шаг N — состояние после N-й команды.
- ▶ / Пробел запускают и приостанавливают проигрывание. Скорость выбирается
  рядом с кнопками; Home / End переходят в начало и конец.
- « / » и список ходов позволяют переходить к границам ходов сторон.
- Нажатие на юнита показывает HP, оставшееся движение и состояния на текущем
  шаге. Нажатие на клетку показывает её координаты и ландшафт.
- Колесо мыши меняет масштаб, перетаскивание сдвигает карту; «Вместить»
  возвращает исходный масштаб.
- Режимы обзора A/B используют фактическую видимость выбранной стороны.
  Это просмотр полного реплея: журнал команд и суммарные показатели армий
  содержат полную информацию о бое.
- Пункт журнала открывает состояние после выбранной команды. Справа также
  отображаются диагностические события CP на этой границе команд.

Стрелка соединяет исходную и конечную клетки последнего действия;
она не изображает промежуточный маршрут. При прерванном движении исходная
цель команды отмечается пунктиром. W / A / C / S / H обозначают воина,
лучника, лучника на колеснице, копейщика и всадника. Полоска — HP;
золотая точка означает использованную атаку.

Библиотека обновляется каждые 30 секунд и кнопкой ↻. Для каталогов матчей
она показывает записи с сохранённым `result.json`; одинаковые повторы
`0`/`1` серии объединены. Одиночный реплей можно открыть без результата.
Некорректный реплей выводит ошибку; он не выдаётся за проверенный.
Просмотрщик сохраняет в памяти до трёх восстановленных реплеев.

Проверки:

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -p test_match_viewer.py -v
.venv\Scripts\python.exe tools\check_combat_viewer.py http://127.0.0.1:8766
```

Браузерная проверка использует установленный Edge и Playwright, проверяет
навигацию, проигрывание/паузу, выбор юнитов, масштаб, обзор, поиск и мобильную
компоновку. Снимки сохраняются в `build/combat-viewer-preview*.png`.
